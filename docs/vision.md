# EduCore Vision

## Mission

To empower schools of every size with a modern, affordable, cloud-native School Management System that simplifies administration, improves communication, and enhances learning.

---

## Vision

To become the leading multi-tenant School ERP platform in East Africa before expanding globally.

---

## Core Principles

- Simplicity first
- Security by default
- Multi-tenant architecture
- Fast performance
- Mobile friendly
- Offline resilience
- API first
- AI ready

---

## Target Users

- Primary Schools
- Secondary Schools
- Colleges
- Universities
- Tuition Centres

---

## Problems We Solve

- Paper-based administration
- Poor parent communication
- Fee tracking
- Attendance
- Report cards
- Inventory
- Staff payroll
- Student lifecycle
